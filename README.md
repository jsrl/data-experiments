# data-experiments
Personal sandbox for learning and testing data engineering stacks.

## Projects

### [md2semantic](./md2semantic/)
ETL pipeline that extracts Markdown files from GitHub, parses them into structured sections, and loads them into PostgreSQL. Designed as a foundation for RAG and Semantic Search.

**Stack**: Python, PostgreSQL, SQLAlchemy, Pydantic, Docker

### [mcp-postgres](./mcp-postgres/)
MCP server for PostgreSQL database interaction via natural language.

**Stack**: Python, PostgreSQL, FastMCP, asyncpg, Docker

## Purpose

Experimenting with:
- Data engineering tools and pipelines
- AI/ML integrations (LLMs, MCP)
- Modern data stack technologies
- Database interfaces and APIs
